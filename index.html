02 /

TEAM PROJECT / DATABASE DESIGN

Starbucks Database Management System

A team database design project for ITDS221 Database Management Systems at Mahidol University, modelling Starbucks beverage ordering, inventory management, and Rewards membership workflows.

The project translates business rules into ER/EER diagrams and a relational schema, with third normal form (3NF) normalization and a data dictionary documenting entity attributes.

  • Database Design
  • ER/EER Modelling
  • Relational Schema
  • Normalization (3NF)
  • Business Rules
  • Data Dictionary
KEY HIGHLIGHTS
  • Analysed ordering, stock replenishment, and loyalty reward processes.
  • Mapped entities and relationships using Chen ER/EER notation.
  • Documented schema transformation, normalization, and attribute definitions.
View project details +
From business processes to a relational model

The repository includes the project report, original and revised ER/EER diagrams, relational schema, and data dictionary. The deliverable focuses on database analysis and design.
